# islamic-notifier

A Claude Code plugin that plays a short recording of a random dhikr (SubhanAllah, Alhamdulillah, La ilaha illallah, Allahu Akbar, La hawla wa la quwwata illa billah, or salawat on the Prophet) whenever Claude finishes responding. It tells you your work is done and ready to check, and it does so as an Islamic reminder. It is built for the terminal CLI and the VS Code extension, on Windows, macOS, Linux and WSL.

**Status:** M1 skeleton: the hook does nothing yet and no audio is bundled; see [docs/PLAN.md](docs/PLAN.md).
